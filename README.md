# NEXORA — Scroll-Based Animated Landing Page

ALGORYX Frontend Internship — Week 2

## 🚀 Project Overview

NEXORA is a modern, responsive AI-focused landing page designed with smooth scroll interactions, animated sections, interactive cards, and a clean premium interface.

## ✨ Features

- Responsive navigation
- Animated hero section
- Smooth scrolling
- Scroll reveal animations
- Parallax effects
- Animated statistics/counters
- Process timeline
- Interactive feature cards
- Testimonials section
- Pricing section
- Validated contact form
- Dark/Light theme
- Scroll progress indicator
- Responsive mobile layout

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Framer Motion
- Lucide React
- CSS

## ▶️ Run Locally

```bash
npm install
npm run dev
```
